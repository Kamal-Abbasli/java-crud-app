# Java CRUD App

A simple CRUD (Create, Read, Update, Delete) web application written in Java.

## Features
- Create a new record
- View the list of records
- Update an existing record
- Delete a record

## Tech Stack
- Java 17+ (tested with Java 27)
- Spring Boot 4.0.8
- Vaadin
- Build tools: Maven (`pom.xml`) and Gradle (`build.gradle`), both with wrapper scripts

## Project Structure
- `src/` - application source code and tests
- `doc/` - screenshots of the running application
- `pom.xml`, `build.gradle` - build configuration
- `mvnw`, `gradlew` - Maven and Gradle wrapper scripts

## Getting Started

### Requirements
- JDK 17 or newer

### Run with Maven
Windows:
    mvnw.cmd spring-boot:run

Linux / macOS:
    ./mvnw spring-boot:run

### Run with Gradle
Windows:
    gradlew.bat bootRun

Linux / macOS:
    ./gradlew bootRun

After the app starts, open http://localhost:8080 in your browser.
